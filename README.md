# Оно тебе надо

Учебный проект Яндекс Практикума: лендинг аукциона «Оно тебе надо».

Репозиторий: https://github.com/cool9595/ono-tebe-nado-ad

## Как посмотреть

Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

## Структура

- `index.html` — разметка страницы;
- `styles/` — общие стили и оформление секций;
- `fonts/` — локальные шрифты Raleway;
- `images/` — изображения лотов, обложка и иконки.

Проверка проекта настроена в `.github/workflows/tests.yml` и запускается при push.
